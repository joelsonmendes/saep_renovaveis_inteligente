# SAEP Renováveis Inteligente — V1

PWA estática para preparação e treinamento da Prova 1 do curso Técnico em Sistemas de Energia Renovável.

## Principais funções
- Navegação por etapas no formato de projeto guiado.
- Modos Aprender, Treinar e Resolver.
- Cálculos da Situação-Problema 01 com memória de cálculo.
- Memorial descritivo e parecer técnico.
- Diagramas didáticos.
- Situação 02 com comissionamento.
- Situação 03 com diagnóstico e registro de manutenção.
- APR.
- Folha pronta para transcrição.
- Banco de equipamentos reais da bancada.
- Validador de string.
- Salvar progresso no navegador.
- Exportar/importar JSON.
- Impressão/Geração de PDF pelo navegador.
- PWA instalável e cache offline.

## Como executar
Use um servidor local simples. Exemplos:
- VS Code + Live Server
- `python -m http.server 8080`
- GitHub Pages / Vercel

Abra `http://localhost:8080`.

## Observação
Ferramenta de treinamento. Em aplicação oficial, utilizar somente se houver autorização da coordenação da avaliação.
